Yukino Tools v0.5.0 新增 Cron 表达式助手、JWT 查看器、正则表达式调试和进程查找，覆盖定时规则检查、接口令牌排查、文本匹配及本机端口定位。

## 新功能

- **Cron 表达式助手**：标准五字段与 Quartz 六 / 七字段，中文字段说明、IANA 时区和未来 10 次执行时间；支持月末、最近工作日、每月第几个星期等规则，可复制表达式与时间列表。
- **JWT 查看器**：本机解析 Header / Payload，支持 Bearer 前缀、iat / nbf / exp、UTC / 本地时间切换及有效期倒计时。签名始终明确标记为“未验证”，未签名与无效时间声明有独立提示。
- **正则表达式调试**：ICU 实时匹配高亮、捕获组、i/m/s 选项、全局替换预览与复制；支持 Unicode 和零宽匹配，后台计算，并限制匹配耗时及结果数量。
- **进程查找**：按名称、启动命令或 TCP 监听端口查找进程，展示 PID、归属和命令，支持复制；确认后可正常结束当前用户的普通进程，操作前重新核对 PID 身份。
- 新工具均接入侧栏、`⌘K` 搜索、收藏、最近使用与菜单栏。

## 下载与安装

要求 **macOS 14+**，预编译包适用于 **Apple Silicon（M 系列，arm64）**。

- **DMG**：下载 `Yukino-Tools-0.5.0-macos-arm64.dmg`，打开后将应用拖到 Applications。
- **ZIP**：下载 `Yukino-Tools-0.5.0-macos-arm64.zip`，解压后将应用移到 Applications。
- **校验**：将 `SHA256SUMS.txt` 与安装包放在同一目录，运行 `shasum -a 256 -c SHA256SUMS.txt`。

发布包采用 **ad hoc 签名**，尚未经过 Apple Developer ID 签名与公证。首次打开若被 macOS 阻止，确认下载来源后，可按“系统设置 → 隐私与安全性”中的系统提示选择“仍要打开”。Intel Mac 可从源码构建，暂未提供经过验证的 Intel 安装包。

## 使用范围

- Cron 只解释和预览，不创建或执行系统任务；预览范围为 1970–2099。标准 Cron 与 Quartz 的星期编号、日期规则分别处理。夏令时不存在的时刻跳过，重复时刻按两个实际时刻列出；实际调度器可能有不同的补偿策略。
- JWT 解码不验证签名、签发者或受众，时间声明来自未验证的 Payload；不支持 JWE 解密，输入上限 256 KB。
- 正则采用 ICU 语法，可能与 JavaScript / Python 不同。匹配时间预算为 0.5 秒，最多保留 1,000 处匹配，超出数量限制时停用替换预览；位置和长度按 UTF-16 计数。
- 进程端口模式只查询本机 TCP LISTEN 服务。系统进程、其他用户与 App 自身只读；不自动提权或强制结束进程，受守护程序管理的服务可能再次启动。
- Cron、JWT 和正则均在本机处理，不上传输入；JWT 与正则文本不保存到历史或设置。
