Yukino Tools v0.8.0 将 cURL 收藏、终端转换与 AI API 调试整合到同一页面，并新增 WorkPilot 工作驾驶舱和 MCP 调试器。

## 主要更新

- **统一 API 调试**：直接粘贴 cURL，发送和停止位于顶部；来源终端默认自动识别，手动选择、内容解析与超时设置收进设置弹窗。移除重复标题和大段引导，左右分栏展示请求和响应。
- **普通 JSON 与 SSE**：JSON 自动格式化，保留大整数、字段顺序和原始数值拼写；可查看原文、响应头、复制或导出。兼容 HTML、普通文本、空响应和 HTTP 错误正文。SSE 保留 Markdown、事件检索、原始流、思考内容及工具调用展示，支持 Chat Completions、Responses、Anthropic、Dify 和通用 SSE。
- **收藏与按需转换**：本机收藏支持搜索、载入、更新、重命名、另存和删除，沿用已有收藏文件。终端转换通过顶部按钮打开弹框，支持 Linux / macOS、Windows CMD 和 PowerShell 的复制与脚本导出。原独立 cURL 入口合并到 AI API 调试。
- **WorkPilot 工作驾驶舱**：统一记录工作事项、待跟进与阻塞，按项目查看进展；从本机 Git 提交和 Codex 已完成会话发现候选工作，确认后纳入日报。支持专注计时、前台应用识别、JSON 备份恢复，以及发送素材到 Codex Desktop 整理日报。
- **MCP 调试器**：支持 stdio 与 Streamable HTTP、工具发现和手动调用、资源与模板读取、Prompt 预览、协议日志与本机演示。
- **统计与日常体验**：Codex 用量支持 `.jsonl.zst` 压缩日志和全部历史视图，读取失败有明确提示；改进菜单栏用量面板、快捷工具和外观主题；OpenRouter 免费周榜支持内嵌数据解析与降级说明。

## 下载与安装

要求 **macOS 14+**。本次预编译安装包适用于 **Apple Silicon（arm64）**。

- `Yukino-Tools-0.8.0-macos-arm64.dmg`：打开后将应用拖到 Applications。
- `Yukino-Tools-0.8.0-macos-arm64.zip`：解压后将应用移到 Applications。
- 将 `SHA256SUMS.txt` 与安装包放在同一目录，运行 `shasum -a 256 -c SHA256SUMS.txt` 校验。

使用 ad hoc 签名，尚未经过 Apple Developer ID 签名和公证。Intel Mac 可从源码构建，未提供经过验证的 Intel 安装包。

## 数据与兼容范围

主动收藏会保存完整原始 cURL（包括其中的凭据），仅保存在本机；独立填写的 API Key 不写入收藏。只有点击发送才联系指定接口；转换不执行请求，工具调用不会自动执行。停止或超时保留已收内容，不自动重试请求。

WorkPilot 的活动记录不自动代表功能完成或已上线；日报交接需要本机 Codex Desktop 及相应日报整理 skill。MCP 首版不支持 OAuth、旧版 HTTP+SSE、订阅或异步任务。Windows 命令覆盖参数往返测试，尚未在原生 Windows 终端执行验证。
