Yukino Tools v0.3.0 新增三个原生 DevOps 工具，将 replaceDocker、pullAndPush 和 nginxfmt 的工作流融入 macOS 工具箱。

## 新功能

- **Docker Mirror**：生成镜像代理拉取、恢复原标签及可选清理步骤；支持代理地址、平台和 sudo。
- **Docker Transfer**：生成 Local → Registry / Registry → Local 的拉取、标签与推送命令；支持带端口的仓库地址和镜像命名空间。
- Docker 命令可逐步预览、复制或导出 Shell 脚本，步骤使用 `&&` 串联，失败即停止；应用仅生成命令，不自动执行 Docker 操作。
- **Nginx Formatter**：原生双栏编辑、格式化与结构检查，支持 2/4/8 空格缩进、LF/CRLF、UTF-8/Latin-1 导入与另存为，保留注释、引号、转义和变量。
- 新增 DevOps 分组、菜单栏入口，以及原工具名称和中文关键词搜索。
- README 新增实际应用截图与原工具分析、集成说明。

## 下载与安装

要求 **macOS 14+**，预编译包适用于 **Apple Silicon（M 系列，arm64）**。

- **DMG**：下载 `Yukino-Tools-0.3.0-macos-arm64.dmg`，打开后将应用拖到 Applications。
- **ZIP**：下载 `Yukino-Tools-0.3.0-macos-arm64.zip`，解压后将应用移到 Applications。
- **校验**：将 `SHA256SUMS.txt` 与安装包放在同一目录，运行 `shasum -a 256 -c SHA256SUMS.txt`。

发布包使用 **ad hoc 签名**，尚未进行 Apple Developer ID 签名与公证。首次打开时 macOS 可能阻止运行；确认下载来源后，可在“系统设置 → 隐私与安全性”按系统提示选择“仍要打开”。Intel Mac 可从源码在本机编译，当前未提供经过验证的 Intel 安装包。

## 使用范围

Docker 工具不内置私库地址或凭据，私库地址由用户填写。重打标签工作流暂不支持 digest 引用。Nginx 结构检查不代替部署环境中的 `nginx -t`，文件上限为 2 MB，暂不支持嵌入 Lua 的配置。另存为默认使用 `.formatted.conf`，不直接覆盖导入文件。

Codex 账户额度来自当前 CLI 的 ChatGPT 登录状态；Token 统计覆盖本机保留日志，上下文为最近请求的估算值。Token Calculator、HTTP Client、DNS Lookup、PostgreSQL、Redis 仍为待实现入口。

## 验证

26 项 Swift Testing 测试通过，其中新增 9 项 DevOps 测试，覆盖镜像引用解析、双向迁移、输入校验、失败后停止及 Nginx 保真、幂等性与结构错误。已验证原生导航、脚本导出、配置导入/另存为、Release 构建、签名完整性和安装包校验。Docker 测试使用假函数，不访问镜像仓库。
