Yukino Tools 的首个公开版本：一个原生 macOS 开发工具箱，将日常转换、网络检测和 Codex 用量放在同一个工作空间。

## 功能

- 原生 SwiftUI 分栏窗口，支持工具搜索、收藏、最近使用记录和菜单栏入口。
- JSON 格式化、压缩、校验、行号、语法高亮和双栏编辑。
- Base64 编解码、秒/毫秒时间戳转换、随机 UUID v4 及批量生成。
- 真实 TCP 端口检测、超时与连接耗时。
- Codex 真实账户额度及重置时间、本机 Token 与缓存统计、上下文估算、会话详情和用量图表。
- Codex 日志增量读取，合并分页与归档，并对重复响应去重；默认每 60 秒刷新。
- 系统/浅色/深色外观、原生设置和键盘快捷键。

## 下载与安装

要求 **macOS 14+**。此版本的预编译包适用于 **Apple Silicon（M 系列，arm64）**。

- **DMG**：下载 `Yukino-Tools-0.2.0-macos-arm64.dmg`，打开后将应用拖到 Applications。
- **ZIP**：下载 `Yukino-Tools-0.2.0-macos-arm64.zip`，解压后将应用移到 Applications。
- **校验**：下载 `SHA256SUMS.txt`，与安装包放在同一目录，运行 `shasum -a 256 -c SHA256SUMS.txt`。

发布包使用 **ad hoc 签名**，尚未进行 Apple Developer ID 签名与公证。首次打开时 macOS 可能阻止运行；确认下载来源后，可在“系统设置 → 隐私与安全性”按系统提示选择“仍要打开”。

## 当前范围

- Codex 账户额度来自当前 CLI 的 ChatGPT 登录状态；Token 统计仅覆盖本机保留日志，上下文为最近请求的估算值。
- Token Calculator、HTTP Client、DNS Lookup、PostgreSQL、Redis 暂仅保留导航入口。
- Intel Mac 可从源码在本机编译，首版尚未提供经过验证的 Intel 安装包。
